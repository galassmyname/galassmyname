## 👋 About me

I'm a **junior software engineer** who builds web applications end to end: REST APIs, real-time features, admin dashboards and the Docker/Kubernetes setup to run them.

- 🎓 **Information Systems**, Université Alioune Diop de Bambey (UADB). Previously a Licence in Systems, Networks & Telecommunications
- 🤖 **P1 Artificial Intelligence**, Sonatel Academy (July → December 2026)
- 🌍 I like problems with a local impact: live bus tracking in Dakar, food delivery in Keur Massar, a French–Wolof dictionary
- ⚡ Currently learning **deep learning**, **LLM applications** and **AI agents**
